AARCHMRS Schema 2.7.4

2.6

Highlights

AARCHMRS-5022: update Types.Field schema to be correct

Updated Types.Field schema to properly support the Features schema. Changes rangeset key of value to be slices and updates the string input mode pattern. Corrected miscellaneous errors with nested objects.

AARCHMRS-4957: Update Tooling for the ASL1 ALP2

To accommodate the changes to ASL1 from the ALP2 release, the following changes were made to the schema:

  • AST.ArrayAccessOp has been created to describe arrays (MYARRAY[[m]]).
  • AST.Assignment has been modified to allow arrays and functions (setters) in variables (FOO() = BAR).
  • AST.Function has been modified to specify parameters in addition to arguments (FOO{foo, bar}(baz, fee)).
  • AST.Identifier 'regex' and 'c_identifier_regex' definitions have been modified to not match names starting with double-underscores (__MY_IDENTIFIER will no longer be matched).

Schema fixes

The SystemAccessor schema was incorrectly representing encodings as an array of an array. This has been corrected to reduce the erroneous double array and now allow an array of Encodings.
